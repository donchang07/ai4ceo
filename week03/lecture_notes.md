## 1. 딥러닝의 직관적 이해

### 1.1 신경망(Neural Network) 구조

```
입력층 (Input Layer)
    ↓
은닉층 (Hidden Layers) × N
    ↓
출력층 (Output Layer)
```

**인간 뇌 뉴런 vs 인공 신경망**:

| 인간 뇌 | 인공 신경망 |
|:--------|:-----------|
| 뉴런 (Neuron) | 노드 (Node) |
| 시냅스 연결 | 가중치 (Weight) |
| 신호 전달 임계값 | 활성화 함수 (Activation Function) |
| 학습 (경험 반복) | 역전파 (Backpropagation) |

> 💡 **비유**: 신경망은 수백만 개의 작은 조절 손잡이(가중치)가 달린 기계로, 학습을 통해 각 손잡이를 최적 위치로 맞추는 과정입니다.

---

### 1.2 주요 딥러닝 아키텍처

| 아키텍처 | 특징 | 주요 용도 |
|:--------|:-----|:---------|
| **CNN** (합성곱 신경망) | 이미지의 공간적 패턴 인식 | 이미지 분류, 얼굴 인식, 의료 영상 |
| **RNN/LSTM** | 순서가 있는 데이터 처리 | 텍스트, 시계열, 음성 인식 |
| **Transformer** | 문맥 전체를 병렬 처리 | GPT, BERT, 번역, 요약 |
| **GAN** | 생성자-판별자 경쟁 학습 | 이미지 생성, 딥페이크 탐지 |
| **Diffusion Model** | 노이즈 제거로 이미지 생성 | DALL-E, Stable Diffusion |

## 2. 대규모 언어 모델(LLM)

### 2.1 LLM이란?

**Large Language Model (LLM)**:
- 수십억~수천억 개의 텍스트 데이터로 사전 학습된 AI 모델
- "다음 단어"를 예측하는 방식으로 언어를 이해하고 생성
- 파인튜닝(Fine-tuning)을 통해 특정 작업에 특화 가능

### 2.2 주요 LLM 비교

| 모델 | 개발사 | 강점 | 특징 |
|:-----|:------|:-----|:-----|
| **GPT-4o** | OpenAI | 멀티모달, 광범위한 지식 | ChatGPT 기반, 가장 널리 사용 |
| **Claude 3.5** | Anthropic | 긴 문서, 안전성, 코딩 | 최대 20만 토큰 컨텍스트 |
| **Gemini 1.5 Pro** | Google | Google 서비스 연동, 멀티모달 | 최대 100만 토큰 컨텍스트 |
| **LLaMA 3** | Meta | 오픈소스, 로컬 실행 가능 | 기업 내부 배포 가능 |
| **EXAONE** | LG AI연구원 | 한국어 특화 | 국내 기업 환경 최적화 |
| **HyperCLOVA X** | NAVER | 한국어 특화 | 한국 문화/법률 이해 |

## 3. 프롬프트 엔지니어링

### 3.1 좋은 프롬프트의 5가지 요소

1. **역할 지정** (Role): "당신은 20년 경력의 McKinsey 컨설턴트입니다."
2. **맥락 제공** (Context): 배경 정보, 회사 상황, 목적
3. **구체적 지시** (Task): 명확한 요청 사항
4. **출력 형식** (Format): 표, 목록, 보고서 형식 등
5. **예시 제공** (Example): 원하는 결과물의 샘플

### 3.2 프롬프트 기법

#### 기본 프롬프트
```
AI 도입 계획서를 작성해줘.
```

#### 개선된 프롬프트
```
당신은 디지털 전환 전문 컨설턴트입니다.
우리 회사(제조업, 직원 500명, 연매출 1,000억)의 AI 도입 3개년 계획서를 작성해주세요.

다음 형식으로 작성해주세요:
1. 현황 분석 (SWOT)
2. 단계별 도입 계획 (1년차/2년차/3년차)
3. 예상 투자 및 ROI
4. 리스크 및 대응방안

각 섹션은 3~5줄로 요약해주세요.
```

### 3.3 고급 프롬프트 기법

| 기법 | 설명 | 사용 상황 |
|:-----|:-----|:---------|
| **Zero-shot** | 예시 없이 바로 요청 | 간단한 작업 |
| **Few-shot** | 2~3개 예시 제공 후 요청 | 특정 형식 필요 시 |
| **Chain-of-Thought** | "단계별로 생각해봐" 추가 | 복잡한 추론 문제 |
| **Role Prompting** | 특정 전문가 역할 부여 | 전문성 있는 답변 필요 시 |
| **Iterative Refinement** | 결과를 보고 지속 개선 | 고품질 결과물 생성 시 |

## 4. 생성형 AI 비즈니스 활용

### 4.1 업무별 활용 사례

| 업무 | 활용 방법 | 기대 효과 |
|:-----|:---------|:---------|
| 문서 작성 | 보고서, 제안서, 이메일 초안 생성 | 작성 시간 50~70% 절감 |
| 데이터 분석 | 데이터 해석, 인사이트 도출 | 분석 속도 향상 |
| 코드 개발 | 코드 작성, 디버깅, 문서화 | 개발 생산성 30~40% 향상 |
| 고객 응대 | 챗봇, FAQ 자동 응답 | 24시간 서비스 가능 |
| 번역/현지화 | 다국어 콘텐츠 번역 | 번역 비용 절감 |
| 이미지 생성 | 마케팅 자료, 프레젠테이션 이미지 | 디자인 비용 절감 |

### 4.2 주의사항 (CEO가 알아야 할 리스크)

⚠️ **Hallucination (환각)**: AI가 없는 정보를 만들어낼 수 있음  
⚠️ **데이터 보안**: 기밀 정보를 외부 AI에 입력하지 않도록 정책 필요  
⚠️ **저작권**: AI 생성 콘텐츠의 저작권 이슈 확인 필요  
⚠️ **품질 검증**: AI 결과물은 반드시 사람이 검토·확인해야 함
