# 표준 챗봇 Streamlit 애플리케이션 생성 프롬프트

다음 요구사항에 따라 Streamlit 기반의 표준 챗봇 애플리케이션을 만들어주세요.
- 파일명은 ref1.py 로 해주고 (ref1.py 가 존재하면, 지우고 다시 생성해줘.)
- 위치는 프로젝트 홈 디렉토리에 해줘.

## 1. 기본 설정

### 1.1 페이지 설정
- 페이지 제목: "표준 잿봇"
- 페이지 아이콘: "📚"
- 레이아웃: "wide"

### 1.2 필요한 라이브러리
```python
import os

```

### 1.3 로깅 설정
- logs 디렉토리에 일별 로그 파일 생성 (chatbot_YYYYMMDD.log)

- INFO 레벨 로그는 출력하지 않음 (ERROR, WARNING만)

## 3. 핵심 기능


### 3.2 구분선 및 취소선 제거 함수
```python
def remove_separators(text: str) -> str:
    - 취소선(~~텍스트~~) 제거
    - 구분선(---, ===, ___) 제거
    - 연속된 빈 줄 정리
```

### 3.3 gpt-5.2 web_search tool 인터넷검색색
- 시스템 메시지에 헤딩 구조화 지시 포함
- 대화 기록 관리 (user/assistant 교차)
- h1, h2, h3로 구조화된 답변 생성

### 3.4 PDF 처리
- PyPDFLoader 사용
- RecursiveCharacterTextSplitter (chunk_size=500, chunk_overlap=100)
- FAISS 벡터 스토어
- 배치 처리 (batch_size=30)
- 검색 결과 수: k=10

### 4.3 스트리밍 모드
- RAG 답변: 스트리밍으로 실시간 표시
- 직접 LLM 답변: 스트리밍으로 실시간 표시
- 스트리밍 중에도 구분선 제거 적용

### 4.4 다음 질문 3개 자동 생성
- 모든 답변 생성 후 자동으로 다음 질문 3개 생성
- 답변 끝에 "### 💡 다음에 물어볼 수 있는 질문들" 섹션 추가
- 번호와 함께 질문 표시
- 생성하는 질문은 현재 답변 내용을 좀 더 상세하게 알기위해서 물어보는 것이어야 한다.

## 5. 대화 관리

### 5.1 대화 기록
- st.session_state.chat_history에 저장
- st.markdown()으로 표시 (헤딩 색상 적용)

### 5.2 대화 맥락 메모리
- conversation_memory에 최근 50개 대화 저장
- RAG 답변 생성 시 이전 대화 맥락 포함

## 6. 특수 기능

### 6.1 구분선/취소선 제거
- 모든 답변에서 자동으로 구분선과 취소선 제거
- remove_separators() 함수 사용

### 6.2 헤딩 색상 스타일링
- CSS로 h1, h2, h3 각각 다른 색상 적용
- st.markdown()으로 표시하여 색상 적용

### 6.3 로깅
- 파일 로그와 콘솔 로그 모두 기록
- ERROR, WARNING만 기록 (INFO는 기록 안 함)
- HTTP 요청 로그는 비활성화

## 7. 에러 처리
- 모든 예외 상황에 대한 적절한 에러 메시지 표시
- 로그에 에러 기록
- 사용자에게 친화적인 에러 메시지

## 8. 환경 변수
- .env 파일에 있다.

## 9. 로그 파일 구조
- 로고 파일: 표준.png (프로젝트 루트)
- 로그 파일: logs/chatbot_YYYYMMDD.log

## 10. 구현 시 주의사항
- 모든 답변은 스트리밍 모드로 생성 (Perplexity 제외)
- 답변 표시는 st.markdown() 사용 (헤딩 색상 적용)
- 구분선과 취소선은 자동으로 제거
- 다음 질문 3개는 모든 답변에 자동 추가
- INFO 레벨 로그는 출력하지 않음
- 사이드바에 구분선(st.divider()) 사용 안 함
- 현재 설정은 st.text()로 표시 (st.info() 사용 안 함)
