10주차. 멀티세션 저장기능

#목적
- supabase를 활용해서 멀티세션이 가능하고 저장이 되도록 하는 RAG 앱을 만듭니다. 

# 파일명
- multi-session-ref.py (이미 있으면 지우고 시작하세요)

# 상세기능
- Supabase 을 활용해서 세션 저장/로드 기능 추가
- 자동 저장: 파일 처리 및 대화 후 자동 세션 저장
- 세션 제목 자동 생성: LLM 기반 제목 생성합니다. 첫번째 질문과 답변을 요약해서 세션명을 만듭니다.
- 멀티선택 바에서 선택을 하면 자동으로 세션을 로드를 해주세요.
- 만일 streamlit 을 중지하고 다시 시작해도 이전 대화는 모두 저장해서 다시 불러 사용할 수 있도록 해주세요.
- vector database도 supabase를 사용해주세요. 따라서 이미 embedding이 된 내용은 다시 사용할 수 있도록 해주세요.
- 이때 embedding은 openai 를 사용해주세요.
- 문서에 대해서 질문에 대한 답변을 할 때, 향후 더 필요한 질문3개를 만들어서 답변 마지막에 추가해주세요.
- 질문을 하면 답변을 모두 완료될때까지 기다려야 하는데, 이것을 stream mode로 변경시켜줘. 즉 내가 질문하면 바로 생성된 답변이 display되도록 하도록 해줘.

# 화면 UI
- LLM을 gpt-5.1, claude-sonnet-4-5, gemini-3-pro-preview 에서 선택하도록 해주세요.
- model name은 니가 생각하지말고, 반드시 여기 써있는대로 그대로 써주세요.
- 세션 관리 UI: 사이드바에 세션 선택, 삭제 기능 버튼을 추가합니다. 
- UI 와 답변, display, color 등은 ref.py를 참고해주세요.
- 챗봇 이름: "PDF 기반 멀티세션 RAG 챗봇" 
- 버튼종류를 다음과 같이 새로 만든다.
1. 세션저장 -- 첫번째 질문과 답변으로 세션명을 만들어서 Supabase에저장한다. 
- 이때, 기존에 저장된 것은 그냥 놔두고, 추가를 해줘. 
- 다시 세션리스트를 클릭하면 거기에는 모든 저장한 세션이 있어야 합니다. 
- 세션을 저장할 때, vector database에 있는 것도 저장해줘야해. 
2. 세션로드 버튼 추가해줘. 내가 원하는 세선을 클릭하고,  세션로드 버튼을 누루면
해당 세션이 화면에 나타나게 해줘.
- 그리고 세션로드를 할 때, vector database에 있는 내용도 다시 retrieval 할 수 있게 해줘. 
3. 세션삭제--- 현재선택된 세션을 지우고, Supabase에 있는 세션도 지운다.
4. 화면초기화 -- 이것은 현재 화면을 모두 지운고 처음부터 다시 시작한다.
- 세션 풀다운메뉴에서 특정한 세션명을 클릭하면 해당 세션의 전체 내용이 화면에 나오게 해주세요.
5. vectordb -- 이것을 누르면 현재 vectordb에 있는 파일명들을 보여주세요.
