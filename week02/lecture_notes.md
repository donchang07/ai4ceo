## 1. 머신러닝이란?

### 1.1 전통적 프로그래밍 vs 머신러닝

```
전통적 프로그래밍:
  입력 데이터 + 규칙(사람이 작성) → 출력 결과

머신러닝:
  입력 데이터 + 출력 결과 → 규칙(AI가 학습)
```

> 💡 **핵심**: 머신러닝은 사람이 규칙을 직접 코딩하지 않고, **데이터로부터 규칙을 자동으로 학습**합니다.

---

### 1.2 머신러닝의 세 가지 유형

#### 지도학습 (Supervised Learning)
- **정의**: 정답(레이블)이 있는 데이터로 학습
- **예시**: 스팸 메일 분류, 신용 점수 예측, 이미지 분류
- **비유**: 정답지가 있는 문제집으로 공부하는 것

#### 비지도학습 (Unsupervised Learning)
- **정의**: 정답 없이 데이터의 패턴을 스스로 발견
- **예시**: 고객 세분화, 이상 탐지, 추천 시스템
- **비유**: 선생님 없이 스스로 규칙을 찾아내는 것

#### 강화학습 (Reinforcement Learning)
- **정의**: 보상과 페널티를 통해 최적 행동을 학습
- **예시**: AlphaGo, 자율주행, 로봇 제어, 광고 입찰 최적화
- **비유**: 게임에서 점수를 높이기 위해 전략을 스스로 터득하는 것

## 2. 데이터: AI의 원료

### 2.1 데이터의 중요성

> "AI에서 데이터는 석유와 같다. 그러나 정제되지 않은 석유는 쓸모없다." – Andrew Ng

**좋은 AI 모델의 조건**:
1. ✅ 충분한 양의 데이터
2. ✅ 다양한 케이스 포함 (대표성)
3. ✅ 정확하고 일관된 레이블
4. ✅ 최신 데이터 (데이터 드리프트 방지)
5. ✅ 편향(Bias) 없는 데이터

### 2.2 데이터 처리 파이프라인

```
데이터 수집 → 데이터 정제 → 탐색적 분석 → 피처 엔지니어링 → 모델 학습 → 평가 → 배포
```

| 단계 | 소요 시간 비율 | 주요 작업 |
|:-----|:-------------:|:---------|
| 데이터 수집 | 20% | DB 연결, API, 웹 크롤링 |
| 데이터 정제 | 40% | 결측치 처리, 이상치 제거, 중복 제거 |
| 탐색적 분석 | 15% | 통계 분석, 시각화 |
| 피처 엔지니어링 | 15% | 변수 변환, 새 변수 생성 |
| 모델 학습/평가 | 10% | 알고리즘 선택, 하이퍼파라미터 튜닝 |

> 💡 **CEO 인사이트**: 데이터 수집·정제에 전체 프로젝트 시간의 60~80%가 소요됩니다. 양질의 데이터 확보가 AI 성공의 핵심입니다.

## 3. 모델 평가 지표

### 3.1 분류 문제의 평가 지표

**혼동 행렬 (Confusion Matrix)**

|  | 예측: 양성 | 예측: 음성 |
|--|:--------:|:--------:|
| **실제: 양성** | TP (진양성) | FN (위음성) |
| **실제: 음성** | FP (위양성) | TN (진음성) |

- **정확도 (Accuracy)**: 전체 중 맞힌 비율 → `(TP+TN)/(TP+TN+FP+FN)`
- **정밀도 (Precision)**: 양성 예측 중 실제 양성 비율 → `TP/(TP+FP)`
- **재현율 (Recall)**: 실제 양성 중 맞힌 비율 → `TP/(TP+FN)`

**비즈니스 적용 예시**:
- 암 진단: 재현율 최대화 (놓치면 위험) 
- 스팸 필터: 정밀도 최대화 (중요 메일을 스팸으로 분류 방지)
- 사기 탐지: F1 스코어 균형 유지

## 4. 과적합과 일반화

### 4.1 과적합(Overfitting) 이해

```
과소적합: 훈련 데이터도 못 맞춤 (너무 단순한 모델)
적정 적합: 훈련·테스트 모두 잘 맞춤 ✅
과적합: 훈련 데이터만 외움, 새 데이터 못 맞춤 (너무 복잡한 모델)
```

> **비유**: 시험 문제를 통째로 외웠지만 비슷한 변형 문제는 못 푸는 학생과 같음

**해결책**:
- 훈련/검증/테스트 데이터 분리 (일반적으로 70:15:15)
- 정규화(Regularization) 기법 적용
- 교차 검증(Cross-validation)
- 더 많은 학습 데이터 확보
